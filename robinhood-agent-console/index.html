Guardrails, not autopilot

Every agent operates inside limits set by the account owner, enforced by the risk sentinel rather than by any single agent's own logic.

  • Max position size: 5% of account value per symbol
  • Daily loss limit: $1,000, hard kill-switch
  • Options exposure: long premium only, no naked writing
  • Every order logged with the signal that triggered it, before submission
